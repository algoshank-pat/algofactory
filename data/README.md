## Data Overview

### `equipment.csv` (20 records)
- Equipment ID, Type (Motor/Pump/Compressor/Fan), Plant, Location, Install Date
- Specs: max_temp_c, max_vibration_mm_s, bearing_type, supplier_id, last_maintenance
- **Total:** 20 equipment across 3 plants

### `anomaly_patterns.md` (12 patterns)
- TH-001, TH-002, TH-003: Thermal anomalies
- VB-001, VB-002, VB-003: Vibration anomalies
- AC-001, AC-002: Acoustic anomalies
- Each includes: symptoms, root causes, detection method, recommended action, parts to stage

### `playbooks.txt` (5 procedures)
- MP-TH-001: Motor Thermal Overload Response (detailed 5-step procedure)
- MP-SEAL-001: Pump Seal Replacement
- MP-COMP-001: Compressor Piston Ring Maintenance (abbreviated)
- MP-VB-BEARING: Bearing Vibration Diagnosis & Replacement
- ~3000 words total across all procedures

### `parts_catalog.json` (10 parts)
- Bearings (6208, 6309), Seals (SA-42), Piston Rings (PR-88), Oils, Thermal Paste, Strainers, Check Valves
- Each with: part_id, description, compatible_equipment_ids, supplier, cost, lead_time_days, specification

## Getting Started: First Steps

### 1. Set Up Environment
```bash
cd C:\Maven\AlgoFactory
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Configure API Keys
Create `.env`:
```
OPENAI_API_KEY=your_key_here
COHERE_API_KEY=your_key_here
PINECONE_API_KEY=your_key_here
PINECONE_ENVIRONMENT=us-east-1-aws
PINECONE_INDEX_NAME=manufacturing-rag
```

### 3. Explore Data
```bash
# View equipment specs
python -c "import pandas as pd; print(pd.read_csv('data/equipment.csv').head())"

# View anomaly patterns
python -c "with open('data/anomaly_patterns.md') as f: print(f.read()[:500])"

# View parts
python -c "import json; print(json.load(open('data/parts_catalog.json'))['parts'][0])"
```

### 4. Start with Loaders
- Implement `src/loaders/csv_loader.py` first (simplest)
- Then `json_loader.py`
- Then `markdown_loader.py` and `text_loader.py` (more complex)

### 5. Test Chunking
```python
from src.loaders.csv_loader import load_equipment
from src.chunking.strategies import semantic_chunk_equipment

docs = load_equipment('data/equipment.csv')
chunks = semantic_chunk_equipment(docs)
print(f"Created {len(chunks)} chunks")
```

## Evaluation: 20 Test Scenarios

All in `evals/scenarios.json`. Format:

```json
{
  "scenarios": [
    {
      "id": 1,
      "difficulty": "easy",
      "query": "Motor-7 thermal overload",
      "expected_topics": ["motor_specs", "thermal_procedure", "bearing_replacement"],
      "expected_answer_keywords": ["reduce load", "bearing inspection", "parts"]
    },
    ...
  ]
}
```

**Metrics:**
- **Retrieval Precision:** Did top-3 chunks contain relevant info? (% of 20 scenarios)
- **Answer Faithfulness:** Is answer grounded in retrieved docs? (% of 20 scenarios)
- **Latency:** End-to-end query time (p50, p95 in seconds)
